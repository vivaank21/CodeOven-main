Help & Answers

Frequently Asked Questions

Got questions about offline capabilities, saving code, or exporting projects? We've got you covered.

Do I need an internet connection to use CodeOven?
No! CodeOven is built offline-first. All rendering, syntax formatting, and live updates occur directly inside your browser's client engine without sending your source code to external servers.
Can I export my projects to build production websites?
Yes, with a single click of the "Export ZIP" button, CodeOven bundles your HTML, CSS, and JS files into an organized zip archive ready for hosting on GitHub Pages, Netlify, Vercel, or any standard web server.
Do I need to create an account to start coding?
No account is required to use CodeOven. You can jump directly into the editor and start building immediately. Creating a free account allows you to securely sync your projects across devices via the integrated backend.
Which web technologies are supported?
CodeOven fully supports HTML5, CSS3 (including Flexbox, CSS Grid, Custom Properties, and animations), and modern JavaScript (ES6+). You can also link external CDN libraries such as FontAwesome, Tailwind, Bootstrap, and Google Fonts.
